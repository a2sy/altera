# Hello Gardener

A tiny test plugin for the [Digital Garden](https://github.com/oleeskild/digitalgarden) plugin system. It shows a friendly badge in the corner of every note — nothing more. Useful for trying out the plugin install flow end to end.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub**, or copy this folder into `src/plugins/hello-gardener/` in your garden repo.

## Settings

- **Badge message** — the text shown in the badge
- **Emoji** — pick the sprout of your choice
